Nginx 版本 当前: {$nginx_version} {if $is_debian_stock}⚠ Debian 自带版本，存在 CVE-2026-42945{/if} 升级到 nginx.org 稳定版

Debian 12 仓库的 nginx 是 1.22.1，不带 CVE-2026-42945 的修复（修复在 1.30.1）。 这里的"升级"会切到 nginx.org 官方 stable 源（一般是 1.30.x），过程：

  • 先把 /etc/nginx 完整备份到 /etc/nginx.bak-<时间戳>
  • 添加 nginx.org 源并 pin（保证以后 apt 都从这里取）
  • apt install nginx 时用 --force-confold 保留你现有的 nginx.conf（含 user www-data; 和 include sites-enabled/*）
  • 禁用 nginx.org 包带过来的 conf.d/default.conf（占 80 会和我们的 vhost 撞）
  • nginx -t 通过才 reload；不通过自动 mv 备份回来 100% 还原

典型耗时 30-180 秒（取决于网络）。过程中你的浏览器连接必然会断一次 —— apt 升级时会先把老 nginx 停掉，正在转发本次 ajax 的 worker 跟着退出， 浏览器看到"请求失败"是预期行为。本页会自动在 30 秒后刷新查看升级结果。 SSH 不受影响。
