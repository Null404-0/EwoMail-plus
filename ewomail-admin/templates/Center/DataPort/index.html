导出

把当前所有邮件数据导出为 SQL 文件（纯 INSERT 语句，不含 schema）。 文件兼容 老版 EwoMail 和 新版 EwoMail-plus：丢到任何一边的 mysql 里都能跑。 不包含管理员账号 / 面板设置 / 收发日志。

下载 SQL 备份
导入 支持新版本导出 + 老版 EwoMail mysqldump
最大 32 MB

导入策略（v1 固定，不可改）：

  • INSERT INTO ... 会被改写成 INSERT IGNORE INTO ... —— 已存在的 email / 域名不会被覆盖。需要替换的话先到「邮件列表」里删旧的。
  • 只挑下面 6 张表的 INSERT 语句： i_users / i_domains / i_aliases / i_bcc_user / i_quota / i_day_record。 其他表（管理员、菜单、系统配置等）一律丢弃，不会污染面板。
  • 不处理邮件正文文件（/ewomail/mail/vmail/...）。如果你在迁移整个服务器，需要另外 rsync 邮件目录过来。

老版 EwoMail 迁移流程： 在老服务器上 mysqldump -uroot ewomail > old.sql，把 old.sql 上传到这里， 然后从老服务器 rsync 邮件目录： rsync -avz old-server:/ewomail/mail/vmail/ /ewomail/mail/vmail/。 重启 dovecot 即可。
